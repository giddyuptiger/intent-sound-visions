# Intent Sound & Visions website

Static rebuild of intentsoundandvisions.com (originally on Wix), for Intent Sound & Visions LLC, Topanga, CA.

Plain HTML and CSS, no build step. Open `index.html` in a browser, or run a local server:

    python3 -m http.server 8000

## Pages

| Path | Page |
| --- | --- |
| `/` | Home |
| `/capabilities/` | Capabilities |
| `/s-projects-side-by-side/` | Portfolio (same address as the Wix site) |
| `/about/` | About |

## Preview status

This copy is a preview. `robots.txt` and a `noindex` tag on every page keep search engines from indexing it, so it does not compete with the live domain. Remove both when the site moves to intentsoundandvisions.com.

Images and the display font were exported from the Wix site and belong to Intent Sound & Visions.
